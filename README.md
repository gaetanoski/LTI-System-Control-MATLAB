# LTI-System-Control-MATLAB
LTI System Analysis and Optimal Control Design (LQR/LQG/LTR)OverviewThis project presents a comprehensive study and simulation of a Linear Time-Invariant (LTI) SISO system. The goal is to analyze the fundamental properties of dynamical systems—such as stability, controllability, and observability—and to design advanced control architectures to achieve high-performance tracking and robustness.+4The project transitions from classical state-space techniques to Optimal Control theory, addressing real-world constraints like sensor noise and non-minimum phase behaviors.+4System DynamicsThe study is based on a second-order system (mass-spring-damper model) defined by the following transfer function:
+2$$G(s) = \frac{0.1}{s^2 + 0.05s + 0.2}$$Parameters used: $m=10$, $c=0.5$, $k=2$.+1Key FeaturesThe implementation in MATLAB covers the following engineering milestones:1. State-Space AnalysisControllability & Observability: Verified through multiple methods, including the Controllability Matrix, Lyapunov Tests, and PBH Tests.+4Stability: Eigenvalue analysis and diagonalizzazione of the A matrix.+2Singular Value Decomposition (SVD): Used to analyze the system's gain properties across different directions.+22. Advanced Control DesignPole Placement: Stabilizing the system by assigning desired closed-loop poles.+1Luenberger Observer: Designing a state estimator to reconstruct the internal state from measured outputs, validated through error convergence analysis.+3Transmission Zeros: Analysis of blocking frequencies and the impact of Right Half-Plane (RHP) zeros on bandwidth limitations.+23. Optimal Control (LQR/LQG/LTR)LQR (Linear Quadratic Regulator): Minimizing an energy-based cost function by solving the Algebraic Riccati Equation (ARE).+2LQG (Linear Quadratic Gaussian): Combining LQR with a Kalman Filter to handle process and measurement noise.+4LTR (Loop Transfer Recovery): Tuning the LQG controller to recover the robustness margins of the original LQR design.
